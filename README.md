# organizador-imposto-renda
Projeto desenvolvido como desafio prático durante o Bootcamp "Santander - Excel com IA e Claude" na DIO (Digital Innovation One)

O objetivo principal desta ferramenta, desenvolvida em Microsoft Excel, é organizar, centralizar e consolidar informações financeiras que normalmente ficam distribuídas em vários documentos, transformando-as em uma estrutura única e de fácil consulta para a preparação da declaração de Imposto de Renda.  

⚠️ *Este projeto possui finalidade exclusivamente educacional e de organização de informações. O arquivo disponibilizado neste repositório para demonstração utiliza apenas dados fictícios e anonimizados.*   

🎯 Estrutura da Ferramenta

A planilha foi estruturada em abas/módulos com responsabilidades específicas dentro da organização dos dados:   
1. TITULAR:
 -  Concentra os dados cadastrais do contribuinte (Nome, CPF, Título de Eleitor, Endereço e Contatos), facilitando a conferência inicial.   
2. INFORMES DE RENDIMENTOS BANCÁRIOS:
- Seção dedicada aos dados financeiros provenientes das instituições. Permite o registro dos valores atuais e cria uma referência direta para os arquivos em PDF dos comprovantes, garantindo a rastreabilidade da informação.   
3. NOTAS (Entradas Financeiras):
-  Estrutura criada para registrar as entradas ao longo do período, identificando a data, a categoria (ex: Holerite) e o valor recebido, criando um histórico financeiro organizado.

🔄 Fluxo de Utilização

O funcionamento da solução segue um fluxo lógico de inserção e validação de dados:   
1. Início ➔ Navegação pelo menu lateral.   
2. Cadastrar Titular ➔ Preenchimento dos dados pessoais essenciais.   
3. Registar Instituições e Valores ➔ Inserção dos dados bancários.   
4. Associar Comprovativos ➔ Ligação aos ficheiros PDF.   
5. Registar Entradas ➔ Preenchimento da tabela de notas (Holerites).   
6. Consolidar Informações ➔ Cálculo automático dos totais gerados pelas fórmulas.   
7. Fim ➔ Conferência dos dados para a declaração oficial.   
  
🧠 Conceitos Técnicos Aplicados

Embora construído no Excel, o projeto envolve conceitos fundamentais de desenvolvimento de sistemas e análise de dados:   
- Organização e Estruturação de Dados: Separação das informações de acordo com a sua finalidade (Cadastros vs. Movimentações).   
- Consolidação Automática: Utilização da função SOMA (SUM) para consolidar automaticamente os valores financeiros registrados nos bancos, reduzindo cálculos manuais e erros.   
- Rastreabilidade: Associação clara entre a informação registrada na planilha e o seu documento de origem (anexos em PDF).

🔐 Segurança e Privacidade

A proteção das informações deve fazer parte do desenvolvimento e da publicação de projetos de portfólio. Nenhum dado real foi utilizado nesta publicação.   
Nunca publique em um repositório público:   
- CPF real   
- Dados bancários e números de conta   
- Endereço residencial completo e telefone pessoal   
- Informes de rendimento reais
